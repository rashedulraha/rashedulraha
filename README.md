Built to be judged on engineering quality, not demo polish: hybrid search with reranking, answers with
citations, an explicit "I don't know" fallback, prompt-injection guardrails, rate limiting, cost logging,
and a published evaluation set (retrieval hit-rate and faithfulness, measured before and after reranking).

## ✅ Engineering practices

- **Typed end to end** — TypeScript on the web, Pydantic on the Python side.
- **Containerised services** with `docker-compose` for local parity; CI on every push.
- **`.env.example` in every repo** — no secrets in version control.
- **Database work through migrations**, with indexes chosen deliberately.
- **For AI features** — evaluation sets before shipping, tracing in production, logged token cost.
